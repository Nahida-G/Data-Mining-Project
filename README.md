# Data-Mining-Project
Liver Patient Data Analysis

A data mining project using a liver patient dataset to analyze patient data and identify patterns associated with liver disease. Using Anaconda and Jupyter Notebook, the project involved data preprocessing, applying machine learning algorithms, evaluating model performance, and visualizing the results.
